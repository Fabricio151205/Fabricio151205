
# ¡Hola! Soy Fabricio Alvarez 👋

Estudiante de **Ingeniería de Sistemas Computacionales** orientado al desarrollo **Full Stack**, **Móvil** e **Infraestructura**. Me apasiona crear software escalable que resuelva problemas reales de gestión, inventario y automatización empresarial.

Actualmente divido mi tiempo entre **prácticas preprofesionales** desarrollando soluciones empresariales y el diseño de arquitectura multicanal (Web + Móvil + IA) para el sector comercial.

---

### 🚀 Proyectos Destacados

#### 🏢 Sistema de Gestión Documental Empresarial *(En desarrollo - Prácticas)*
> **Enfoque:** Aplicación Web corporativa diseñada para centralizar, registrar y auditar el flujo de documentos internos.
> 
> **Key Skills:** Desarrollo Web, Arquitectura de Software, Seguridad y Gestión de Procesos.

#### 📱 Vape On — E-Commerce & Gestión Integral con IA *(Web + Móvil)*
> **Enfoque:** Solución multicanal compuesta por una app móvil de pedidos para clientes, un panel administrativo de ventas presenciales y un modelo de Inteligencia Artificial propio.
> 
> - **Móvil (Android/Firebase):** Aplicación de pedidos con vistas diferenciadas por rol (Cliente vs. Administrador) e integración de IA para predicción y alertas automáticas de stock.
> - **Web (ASP.NET Core / SQL Server):** Plataforma orientada a la presencia institucional, catálogo e integración de ventas en local.
> - **Sincronización:** Arquitectura desacoplada que comparte base de datos e información en tiempo real entre ambas plataformas.
